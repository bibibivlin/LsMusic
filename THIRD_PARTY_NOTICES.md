# Third-party notices

## Protocol and design references

The online lyrics implementation was informed by the following open-source projects. Their source
code is not bundled as a binary dependency.

- [jitwxs/163MusicLyrics](https://github.com/jitwxs/163MusicLyrics), used as a reference for
  NetEase Cloud Music and QQ Music request protocols. Licensed under the
  [Apache License 2.0](https://github.com/jitwxs/163MusicLyrics/blob/master/LICENSE).
- [cqjjjzr/MusicBee-NeteaseLyrics](https://github.com/cqjjjzr/MusicBee-NeteaseLyrics), used as a
  reference for anonymous NetEase Cloud Music search and lyric requests. Licensed under the
  [Apache License 2.0](https://github.com/cqjjjzr/MusicBee-NeteaseLyrics/blob/master/LICENSE).
- [dokar3/amlv](https://github.com/dokar3/amlv), used as a behavioral and visual reference for the
  Compose lyrics animation. Licensed under the
  [Apache License 2.0](https://github.com/dokar3/amlv/blob/main/LICENSE).

[applemusic-like-lyrics](https://github.com/amll-dev/applemusic-like-lyrics) and
[BetterLyrics](https://github.com/jayfunc/BetterLyrics) were used only for visual research. No code
from those projects is included.
